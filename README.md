# My Attendance Android

Offline personal attendance app for Android.

Features:
- One-tap Punch In / Punch Out using phone time
- Present, Absent, Paid Leave, Unpaid Leave, Half Day, Holiday, Week Off
- Standard working duration in hours + minutes
- Overtime calculated from worked duration beyond the standard duration
- AM/PM and 24-hour display modes
- Monthly summary and attendance history
- CSV import/export
- Local offline storage

The APK is built automatically with GitHub Actions.
